# 🛡️ SECURITY.md

## Модель безопасности проекта

Analytical Platform Pro спроектирована с учетом предотвращения наиболее распространенных уязвимостей в приложениях для анализа данных.

### 1. Аутентификация и хранение паролей
- **Механизм**: Bcrypt (Blowfish).
- **Реализация**: Пароли пользователей никогда не хранятся в открытом виде. При каждой проверке используется уникальная соль (salt), что делает невозможным атаку радужными таблицами.
- **Публичный доступ**: Весь функционал дашбордов скрыт за формой входа в `streamlit_app.py`.

### 2. Защита при экспорте данных (Excel Formula Injection)
Это критическая уязвимость для платформ анализа данных.
- **Проблема**: Excel интерпретирует ячейки, начинающиеся с `=`, `+`, `-`, `@`, как формулы, что может привести к выполнию команд на ПК пользователя.
- **Решение**: [app/services/export_service.py](app/services/export_service.py) автоматически добавляет префикс `'` (одинарная кавычка) ко всем подозрительным строковым значениям перед сохранением в `.xlsx`.

### 3. Безопасность файловой системы (Path Traversal)
- **Валидация**: При загрузке новых CSV через веб-интерфейс, имена файлов нормализуются с помощью регулярных выражений (`re.sub(r'[^a-zA-Z0-9_]', ...)`.
- **Изоляция**: Загруженные файлы сохраняются исключительно в директорию `data/Uploads/`.

### 4. XSS (Cross-Site Scripting)
- **Защита**: Приложение не использует `unsafe_allow_html=True`. Рендеринг данных в таблицах и графиках осуществляется через нативные компоненты Streamlit и Plotly, которые автоматически экранируют потенциально опасные скрипты в содержимом CSV.

### 5. Безопасность ресурсов (DoS Protection)
- **Memory Limits**: Внедрены лимиты на количество кешируемых датасетов (`max_entries` в `@st.cache_data`).
- **Input Limits**: Максимальное количество виджетов на одном дашборде ограничено программно, чтобы предотвратить переполнение оперативной памяти.

---

### Рекомендации для Production Deployment
1. **HTTPS**: Всегда используйте TLS/SSL сертификаты (например, через Nginx), так как cookies сессий передаются по сети.
2. **Database Backup**: База данных SQLite (`users.db`) должна регулярно архивироваться.
3. **Secrets Management**: Вынесите конфиденциальные пути (BASE_DIR) в переменные окружения.
